# Portfólio · Tiago Satilio

Site pessoal de Tiago Satilio, desenvolvedor Full Stack (IA, web e mobile).

## Estrutura

```
portfolio-tiago/
├── index.html        estrutura e conteúdo da página
├── css/
│   └── style.css     estilos (cores, fonte e layout no início do arquivo)
├── js/
│   └── script.js     animações e botão de tema claro/escuro
└── images/
    └── fundo.jpg     foto de fundo da abertura
```

## Como rodar

Abra o `index.html` no navegador, ou use a extensão **Live Server** do VS Code
(botão direito no `index.html` > *Open with Live Server*).

## Onde editar

- **Cores e fonte:** bloco `:root` no início de `css/style.css`.
- **Textos:** seções `#inicio`, `#sobre` e `#contato` em `index.html`.
- **Frases do cargo:** variável `frases` em `js/script.js`.
- **Foto de fundo:** substitua `images/fundo.jpg` mantendo o nome.

## Publicar

Envie a pasta inteira para o **GitHub Pages** ou o **Netlify Drop**.
